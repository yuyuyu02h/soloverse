## Activation / Rollback

実際の.envや稼働用DBの内容は変更していない（ユーザー依頼による非公開バックアップのみ）。更新後にバックエンドを再起動すると、追加テーブルを作り、新方式が既定で有効になる。世界再生成・DB削除は不要。フロントエンドも更新版で起動する。
